# Week 1 — Research, Requirement Analysis and Setup
**Group 8 | PolyGen: Generative Text-to-3D Asset Pipeline**

## Goal
Understand the problem, identify requirements, sketch the pipeline, and prepare a development environment.

## Planned/recorded activities for the project starter
- Review the text-to-3D concept and use cases.
- Define the input as natural-language object descriptions.
- Define the prototype output as a previewable/exportable 3D mesh.
- Outline architecture and development milestones.
- Prepare Python project structure and dependency list.

## Initial requirements
- Text prompt input
- Prompt parsing
- Geometry generation module
- 3D preview
- OBJ export
- Later: real generative model/API integration

## Architecture (initial)
User Prompt → Prompt Processing → 3D Generation Component → Preview/Export
